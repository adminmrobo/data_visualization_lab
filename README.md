# 데이터 시각화 연구실

## 1편 · 시각화 차트 도감

데이터 분석에서 자주 만나는 차트 32장을 6교시로 나눠 배우는 연구실 수업입니다. 그림 모양을 외우기보다, 그림마다 **어떤 질문에 답하는지**와 **어떻게 잘못 읽기 쉬운지**를 먼저 봅니다.

- 페이지: `index.html` (한 파일로 열립니다. 3D 지도만 three.js r128을 CDN에서 불러옵니다)
- 자매편: [확률분포 딕셔너리](https://adminmrobo.github.io/probability_distribution_dictionary/)

| 교시 | 답하는 질문 | 차트 |
|---|---|---|
| 1 분포 보기 | 값들이 어떻게 퍼져 있나? | 히스토그램·밀도곡선, 상자그림·바이올린, 누적분포(ECDF), QQ 플롯, KS 플롯 |
| 2 관계 보기 | 두 변수가 함께 움직이나? | 산점도, 산점도 행렬, 상관 히트맵, 교차분석표·모자이크, 잔차 플롯 |
| 3 모델 평가 | 모델이 맞혔나, 어떻게 틀렸나? | 혼동행렬, 1종·2종 오류 그림, ROC, 정밀도-재현율, 보정 곡선, 리프트·이득 |
| 4 진단과 해석 | 잘 배웠나, 왜 그렇게 판단했나? | 편향-분산, 학습 곡선, 손실 곡선, 지니·엔트로피, 특성 중요도, SHAP, PDP·ICE |
| 5 줄이기·묶기 | 차원을 줄일 수 있나, 무리로 묶을 수 있나? | 스크리·누적 설명분산, PCA 바이플롯, t-SNE·UMAP, 엘보, 실루엣, 덴드로그램 |
| 6 시계열 | 시간에 따라 어떻게 변하나? | 선 그래프·이동평균, 시계열 분해, ACF·PACF |

### 페이지 구성
표지(3줄 요약·약어 풀이) → 오늘의 교실 → **3D 관계 지도**(가로 분석 단계 · 높이 데이터 종류 · 앞뒤 교시, 선 = 함께 보는 짝 32쌍) → 큰 그림 → 1~6교시 → 대결(정확도 99% 사기 탐지 모델) · AI 판단 코너 → 쪽지시험 → 참고 문헌 → 수업을 마치며 → 지식 색인(#kg) · 꾸러미(#export)

교시마다: 박사의 현장 질문 → 「왜 이 그림들을 쓰나」 + 「하루가 대신 묻는 수식」(숫자로 한 번 해 보기) → 일상·회사 → 단계 대화 → 실험 패널 → 한계 → 접은 파이썬 코드 → 차트 카드(질문 · 읽는 법 · 흔한 오독 · 짝 · 파이썬 · 생성 AI 프롬프트) → 확인 퀴즈 → 하루의 세 줄 정리

### 등장인물 (이번 특집의 역할)
- 선생님: 박사
- 조교: 주판봇(계산·코드, 성급한 확신), 초파리(눈·감각, 짝 그림 안내, 의심)
- 수강생: 하루(수식 질문·세 줄 정리), 시아, 모아, X1·X2·X3(흔한 오독 담당)

## 다시 만들기

```sh
sh build/build.sh
```

1. `build/gen.js` — `content.js`(카드·대사·교시 내용) + `app.js`(차트 그리기·실험·3D 지도) + `page.src.html` + `sprites.js`(캐릭터 팩 30장)로 `index.html` 조립
2. `build/kg_build.py` — `kg/kg.json`·`refs.json`·`meta.json` 생성 (노드 90 · 관계 206 · 문헌 7)
3. `build/tools/retrofit.py`로 지식 색인·꾸러미를 붙이고 `check.py`로 점검 → `kg/check_report.md` (오류 0, 경고 1: 라이선스 공란)
4. 숫자 예시 검산: `python3 build/check_numbers.py`

모든 실험 데이터는 정해진 난수(시드 고정)로 만든 교육용 예시입니다.
