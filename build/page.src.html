시각화 차트 도감

히스토그램부터 SHAP, 실루엣, 자기상관까지 데이터 분석에서 자주 만나는 차트 32장을 6교시로 나눠 배웁니다. 그림 모양을 외우기보다, 그림마다 어떤 질문에 답하는지와 어떻게 잘못 읽기 쉬운지를 먼저 봅니다.

글 · 안상선 ((주)M-Robo 대표) · 자매편 확률분포 딕셔너리
32차트 카드

32함께 보는 짝 관계
3축단계 · 데이터 · 질문 지도
처음 오신 분께 — 이 페이지를 3줄로
  1. 무엇을: 차트 32장이 각각 어떤 질문에 답하는지, 어떻게 읽고 어떻게 잘못 읽기 쉬운지 배웁니다.
  2. 왜 중요한가: 같은 데이터도 그림을 잘못 고르거나 잘못 읽으면 반대 결론이 나옵니다.
  3. 회사에서는: 보고서 그래프를 고르고, AI가 그려 준 그래프를 검토할 때 바로 씁니다.
수식이나 코드를 몰라도 됩니다. 코드는 모두 접어 두었고, 카드마다 생성 AI에게 그대로 부탁할 수 있는 문장을 붙였습니다.

오늘의 교실

이번 특집에서는 연구실이 교실이 됩니다. 박사가 선생님, 주판봇과 초파리가 조교, 나머지 식구 여섯이 수강생입니다.

3D 관계 지도 — 차트 32장은 어디에 있나

가로는 분석 단계(탐색 → 확인·비교 → 모델링·평가 → 설명), 높이는 다루는 데이터(연속값 · 범주·개수 · 시간 순서 · 모델 점수·예측), 앞뒤 줄은 교시(답하는 질문)입니다. 선은 함께 보면 좋은 짝입니다.

이 브라우저에서는 3D 지도를 그릴 수 없습니다. 아래 교시별 카드에서 같은 내용을 볼 수 있습니다.
이름표를 누르면 그 차트와 짝 관계가 강조됩니다.
차트 이름으로 고르기 (32장 목록)

조작 끌어서 돌리기, 휠(두 손가락)로 확대. 이름표가 겹쳐 숨은 차트는 그림 판을 직접 누르거나 아래 목록에서 고르세요. 읽는 법 같은 높이·같은 가로 위치에 모인 차트는 같은 종류의 데이터를 같은 단계에서 다룹니다. 3교시·4교시 차트가 오른쪽 위(모델 점수, 평가·설명)에 몰려 있는 것은 그 그림들이 데이터가 아니라 모델이 낸 숫자를 그리기 때문입니다.

큰 그림 — 6교시 순서

교시는 앞 교시의 한계가 다음 교시의 이유가 되도록 이어집니다. 변수 하나(분포) → 둘(관계) → 모델이 낸 답(평가) → 모델 속(진단·해석) → 변수 수십 개(줄이기·묶기) → 시간(시계열).

VS대결 — 정확도 99% 사기 탐지 모델, 도입할까?

거래 10,000건 중 사기는 100건(1%)입니다. 모델 A는 모든 거래를 ‘정상’이라고 합니다. 모델 B는 3교시 실험의 점수 모델(양성 점수 평균 2, AUC 약 0.92)입니다. 사기 한 건을 놓치면 100만 원 손실, 헛경보 한 건을 확인하는 데 1만 원이 든다고 합시다(숫자는 교육용 예시입니다).

초파리 팀 — 모델 B (혼동행렬 우선)

AI 판단 코너 — 이 보고서, 어디가 이상할까요?

생성 AI에게 두 모델을 비교해 달라고 했더니 이런 문장이 돌아왔습니다.

“모델 A는 정확도 99.0%로 모델 B(93.1%)보다 6%p 높습니다. 따라서 모델 A의 도입을 권장합니다.”

숫자 자체는 맞습니다. 그런데 결론을 믿기 전에 확인할 것이 있습니다. 직접 생각해 본 뒤 단추를 눌러 보세요.

  1. 양성 비율 — 사기가 1%뿐이면 ‘전부 정상’도 정확도 99%가 나옵니다. 기준이 되는 무작위 모델의 정확도부터 물어야 합니다.
  2. 혼동행렬 — A의 재현율은 0%입니다. 사기를 한 건도 잡지 못합니다.
  3. 비용 — 두 실수의 비용이 다르면 정확도가 아니라 비용으로 비교해야 합니다. 위 예시에서는 B가 훨씬 쌉니다.
